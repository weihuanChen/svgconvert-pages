## 🎯 产品概述

SVG Converter 是一款免费、快速、无需登录的在线文件转换工具，支持 SVG、PNG、JPG、PDF 等多种格式的相互转换。

### 核心价值

| 特性 | 说明 |
|------|------|
| **免费** | 完全免费，无付费限制 |
| **快速** | 平均转换时间 < 5 秒 |
| **安全** | 文件自动清理，30 分钟后自动删除 |
| **多语言** | 支持中文、英文、日文 |
| **无需登录** | 开箱即用，无账户要求 |
| **支持移动** | 完全响应式设计 |

## ✨ 核心功能

### 1. 文件格式转换

#### 支持的转换矩阵

| 输入\输出 | SVG | PNG | JPG | PDF |
|----------|-----|-----|-----|-----|
| **SVG** | ✅ | ✅ | ✅ | ✅ |
| **PNG** | ⏳ | ✅ | ✅ | ✅ |
| **JPG** | ⏳ | ✅ | ✅ | ✅ |
| **PDF** | ⏳ | ✅ | ✅ | ✅ |

**说明**: ✅ 已支持，⏳ 计划支持

#### SVG → PNG/JPG 转换

**功能**:
- 将矢量图转换为位图
- 自定义输出尺寸
- 调整图像质量
- 设置背景颜色

**参数**:
- **宽度/高度**: 自定义像素尺寸
- **质量**: 1-100% (默认 85%)
- **背景**: 透明或自定义颜色
- **纵横比**: 保持原始比例选项

#### SVG → PDF 转换

**功能**:
- 将 SVG 转换为可打印的 PDF
- 保留矢量信息
- 支持多页面
- 优化打印输出

#### PNG/JPG 转换

**功能**:
- PNG 和 JPG 相互转换
- 调整色彩深度
- 优化文件大小
- 支持透明度处理

### 2. 上传和处理

#### 文件上传

**支持方式**:
- 拖放上传（Drag & Drop）
- 点击浏览选择
- 支持多文件上传
- 支持粘贴上传

**文件限制**:
- 单个文件 ≤ 20MB
- 批量最多 5 个文件
- 支持的格式: SVG, PNG, JPG, PDF

#### 实时进度反馈

**显示内容**:
- 上传进度百分比
- 转换进度状态
- 预计完成时间
- 错误提示

### 3. 下载和导出

#### 单文件下载

- 立即下载转换后的文件
- 自定义文件名
- 正确的 MIME 类型
- 完整的文件元数据

#### 批量下载

- 支持多文件批量处理
- 可选 ZIP 压缩打包
- 保留原始文件名
- 一键下载所有文件

## ⚙️ 用户自定义选项

### SVG 转 PNG/JPG 设置

| 选项 | 范围 | 默认 | 说明 |
|------|------|------|------|
| **宽度** | 16-4096 px | 原始宽度 | 输出宽度 |
| **高度** | 16-4096 px | 原始高度 | 输出高度 |
| **质量** | 1-100% | 85% | JPG 压缩质量 |
| **背景** | 颜色选择 | 透明 | 背景色或透明 |
| **缩放** | 0.1-10x | 1x | 等比缩放 |

### PNG 优化选项

- **压缩级别**: 0-9 (默认: 6)
- **删除元数据**: 选项开关
- **转为灰度**: 选项开关

### PDF 输出选项

- **纸张大小**: A4, Letter, Custom
- **边距**: 自定义毫米
- **分辨率**: 72, 96, 150, 300 DPI

## 🎯 功能使用流程

### 基础流程

```
1. 打开应用
   ↓
2. 拖放或点击上传文件
   ↓
3. 选择输出格式
   ↓
4. 调整参数 (可选)
   ↓
5. 点击"开始转换"
   ↓
6. 等待转换完成
   ↓
7. 点击"下载"保存文件
```

### 高级流程 (批量处理)

```
1. 上传多个文件 (最多5个)
   ↓
2. 为所有文件选择相同的输出格式
   ↓
3. 配置统一的转换参数
   ↓
4. 批量开始转换
   ↓
5. 等待所有文件完成
   ↓
6. 批量下载或打包下载
```
