## 📊 功能参数

### SVG 转 PNG/JPG

| 参数 | 范围 | 默认 | 说明 |
|------|------|------|------|
| 宽度 | 16-4096 px | 原始 | 输出宽度 |
| 高度 | 16-4096 px | 原始 | 输出高度 |
| 质量 | 1-100% | 85% | JPG 压缩质量 |
| 背景 | 颜色选择 | 透明 | 背景色或透明 |
| 缩放 | 0.1-10x | 1x | 等比缩放 |

### PNG 优化

- 压缩级别: 0-9 (默认: 6)
- 删除元数据: 开关
- 转为灰度: 开关

## 📱 使用场景

### 平面设计师
- 推荐: SVG → PNG (高分辨率)
- 参数: 宽度 2048px, 质量 95%
- 用途: 准备打印文件

### Web 开发者
- 推荐: SVG → PNG (响应式)
- 参数: 宽度 512px, 背景透明
- 用途: 网站资源

### 办公用户
- 推荐: SVG → PDF
- 参数: A4 纸张, 300 DPI
- 用途: 报告和演示

### 内容创作者
- 推荐: SVG → JPG (社交媒体)
- 参数: 宽度 1200px, 质量 85%
- 用途: 社交平台分享

## 🎯 使用流程

### 基础流程

```
1. 打开 https://svgconvert.net
2. 拖放或点击上传文件
3. 选择输出格式
4. 调整参数（可选）
5. 点击"开始转换"
6. 等待转换完成
7. 点击"下载"保存
```

### 批量处理

```
1. 上传多个文件 (最多5个)
2. 选择统一的输出格式
3. 配置转换参数
4. 批量开始转换
5. 等待全部完成
6. 批量或打包下载
```
